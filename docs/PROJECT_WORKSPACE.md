# Projects and Elements

Start directly in Production or create/open a project. Save scene to copies the current setup into a new scene/shot in the selected project. Elements holds reusable image/video/audio assets, categories and folders. Edit names, categories and notes without changing asset identity. Shot mention names are separate from catalog names.

Type @ to search names/aliases. Choosing an element attaches it and inserts a valid mention; prompt edits during loading prevent stale insertion. Removing a shot reference leaves its catalog original intact. The catalog may exceed one generation's [reference limits](COMPATIBILITY_MATRIX.md).

Replace beside an image reference changes that shot only. Replace image in Elements updates editable bindings, while archived takes retain originals. Revisions/request identities protect concurrent edits and lost responses. Export includes unused registered assets too.

Generations/Favorites use the selected scope. All server videos includes unassigned files without guessing ownership. Download is available on cards. Shared Activity tracks queue/preparation/exports. Export completion requires verification and survives tab closure. CPU Lanczos enlarges frames with copied audio, without new diffusion detail.

Server project saves are distinct from local drafts. Open uses another tab while generation/loading is busy. Large catalogs paginate previews but search all entries. Thumbnails never replace original graph inputs.
