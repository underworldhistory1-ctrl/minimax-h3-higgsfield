# المشاهد واللقطات داخل المشروع

المشروع يجمع مكتبة Elements المشتركة والمشاهد التي تنشئها بنفسك. لا تُنشأ Scene 1 أو Scene 2 تلقائيًا.

ابدأ بـCreate Scene واكتب اسم المشهد، ثم Create Shot لإضافة لقطة. كل لقطة تحفظ البرومبت وإعدادات التوليد وربط المراجع الخاص بها؛ تغيير المشهد لا ينسخ تلك الإعدادات إلى المشهد التالي. يمكنك إعادة التسمية والنسخ وتغيير الترتيب. نسخ المشهد أو اللقطة ينسخ إعداداتها بهويات جديدة، ولا يكرر سجل الفيديوهات الأصلية.

المراجع الأصلية موجودة مرة واحدة في Elements على مستوى المشروع. اختيار مرجع للقطة لا يغيّر اختيار لقطة أخرى. عند غياب أصل مطلوب، تظل رسائل المدخلات الناقصة مانعة للرندر بدل تجاهله.

## المشاريع الموجودة

المسودة والفيديوهات القديمة تظل متاحة في Legacy content. لا ننسب الفيديوهات السابقة إلى مشهد بالتخمين ولا نغير هويات المشاريع أو الأصول أو اللقطات أو النتائج. يمكن نسخ إعداد قديم إلى لقطة تختارها، مع الاحتفاظ بالأصل.

## الحفظ والرندر وReuse

يحفظ التنقل المسودة قبل فتح الهدف. فشل الحفظ أو تعارض جهاز آخر يمنع استبدال المحرر بالهدف. اختيار المشهد واللقطة يخص التاب الحالي، بينما المحتوى نفسه محفوظ في المشروع على السيرفر.

الرندر يحتفظ بهوية المشروع والمشهد واللقطة وقت الإرسال. النتيجة ترتبط بتلك الهوية، وليس بالتبويب المفتوح عند انتهاء الرندر. Reuse يستعيد البرومبت والإعدادات والمراجع إلى اللقطة المختارة ويفتح Production؛ لا يبدأ توليدًا تلقائيًا.

الحذف يحمي المشاهد واللقطات المرتبطة بنتائج أو وظائف أو اعتماديات؛ لا يحذف الفيديوهات أو الأصول المشتركة. التصدير والاستيراد يحتفظان ببنية المشاهد ومراجعها وفق حدود حزمة المشروع الحالية.

## نطاق التحقق

اختبارات الخدمة تتحقق من الهويات والمراجعات والملكية والتوافق القديم، واختبارات JavaScript تتحقق من التنقل والحفظ وReuse. فحص المتصفح يثبت رحلة الاستخدام، ولا يثبت جودة رندر GPU لكل إعداد أو تركيبة مراجع.
