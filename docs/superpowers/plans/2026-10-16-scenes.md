# Scenes and shots implementation plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement task-by-task.
**Goal:** Durable user-created scene and shot workspaces integrated with existing H3 projects.
**Architecture:** Additive nested scenes/shots in the existing project manifest; stable snapshot ownership; client-tab selection and current draft compatibility.
**Tech Stack:** Python/aiohttp, vanilla JavaScript, existing revisioned JSON manifests.
**Spec:** docs/superpowers/specs/2026-10-16-scenes-design.md

No predefined scenes. Keep existing project/clip/asset/take/job IDs and media. No new GPU inference in deployment tests. No overlapping state registry. Missing references fail closed. Independent revisions across devices. No dependency or CUDA stack replacement.
