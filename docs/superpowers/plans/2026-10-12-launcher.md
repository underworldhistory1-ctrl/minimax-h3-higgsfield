# Automatic H3 Launcher Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent models and smoke modules. Central integration stays with the coordinator.

**Goal:** One resumable, storage-aware entry point that provisions a compatible H3 studio and reports actual validation.
**Architecture:** Standard-library orchestrator calls existing platform installers for pinned source/runtime setup, a shared model planner/downloader first, and a persisted smoke job last. Existing entry points redirect to the launcher unless its internal environment flag is set.
**Tech Stack:** Python 3.10+ orchestration, Bash and PowerShell wrappers; existing ComfyUI Python environment.
**Spec:** docs/superpowers/specs/2026-10-12-launcher.md

## Global Constraints

- Preserve projects, outputs, shared models and user source edits.
- Default bind 127.0.0.1. Turbo opt-in; default Qwen INT8, Refine and ControlNet.
- Sequential downloads, bounded retries, exclusive installation lock and atomic JSON.
- Reports separate files_prepared, api_ready and gpu_validated.
