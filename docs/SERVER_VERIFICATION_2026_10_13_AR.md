# مراجعة السيرفر والإصدار 2.1.1 — 13 أكتوبر 2026

تمت مقارنة التعديلات الموجودة على HyperAI بالمصدر، ثم دمجها في الإصدار الجديد. لم نعتمد على مجرد ظهور الصفحة أو جاهزية API.

## ما تم دمجه
- صورة ثابتة أو صورة خريطة تحكم جاهزة، بالإضافة إلى فيديو المصدر وفيديو التحكم الجاهز. الصورة تتكرر كتوجيه ثابت طوال المدة، بلا اختراع حركة أو تقسيم تلقائي للستوري بورد.
- تجهيز Canny/Gray/Pose/Depth حسب المعالج المتاح، والمحافظة على تركيب الصورة عبر Text/Frames/References. حذف المخرجات المؤقتة عند الإلغاء أو الخطأ وفحص عدد الفريمات والمقاس.
- اختيار الفيديو المُولد ذي type=output بدل معاينة ControlNet ذي type=input.
- حفظ واستعادة Automatic كما اختاره المستخدم، وتصحيح اسم Ref2VA/FL2VA الظاهر حسب المود الفعلي.
- شرح عربي سياقي للموديلات والمراجع والتحكم والستوري بورد وخيارات الصوت، مع المحافظة على واجهة Studio الحالية.

## الدليل الحي
- السيرفر الحالي: NVIDIA RTX 5090، 32GB VRAM تقريبًا، حد RAM حوالي39GB. فحص الطابور وجد صفر مهام.
- تدقيق البيئة: PyTorch2.9.1+cu130،CUDA13.0،فحص اتساق الاعتمادات بلا مشاكل؛ اختبار CUDA صغير نجح. فحص البيئة نفسه لا يدعي تحقق جودة GPU.
- ملفات التشغيل الـ120 كانت مطابقة للمصدر المعدّل على السيرفر.
- Original FL2VA/Ref2VA وVAE/encoder واللورات الأربع وControlNet ومعالجاته الأربع ظاهرين متاحين. ملف Turbo القديم محتفظ به على القرص لكن غير معروض أو محمّل في الواجهة.
- Singularity متاح في catalog؛ الإتاحة ليست شهادة جودة رندر.
- مهمة GPU السابقة e17ed854-89fc-487c-abd6-a438b9fcb93e مكتملة ومربوطة بفيديو الإخراج الصحيح. راجعنا الملف بصورة مستقلة وفككنا الفيديو والصوت بالكامل بنجاح.
- ملف h3_studio_a6e56d03cdba_00001_.mp4: H.264،864×480،124فريم،24fps،5.166667ثانية؛ AAC،5.167ثانية. SHA256: ac87a908edadf6c62b33480ad59d70c550dd8e07d1a4f11be5bf7e980c4900f1.
- إعدادات المهمة المحفوظة: Original Ref2VA،native،20steps،res_multistep/simple،CFG1،صورة مرجعية + Canny من صورة ثابتة،strength1. سجل ComfyUI المؤقت كان قد اتفرغ بعد إعادة التشغيل؛ استخدمنا سجل المهمة الدائم والملف الناتج، ولم ندّع وجود history قديم غير موجود.
- اختبار متصفح حقيقي من رابط HTTPS، بدون API fixtures: الواجهة والـreadiness يعملان، مداخل الصور موجودة، أسماء الموديلات صحيحة، أربع لورات دون Turbo، Automatic افتراضي، ولا أخطاء JavaScript أو overflow على الموبايل.
- 289 اختبار Python و139 JavaScript نجحوا محليًا، ومراجعة الباك إند والواجهة بلا ملاحظات مهمة.

## الحدود
الفيديو كان مولدًا بالفعل في سيشن التثبيت؛ المراجعة الحالية تحققت من النتيجة بشكل مستقل ولم تُشغّل رندر GPU إضافيًا. هذا يثبت المسار المختبر المحدد فقط. لا توجد شهادة لكل دقة أو مدة أو LoRA أو acceleration. Singularity وHybrid وCharacter Swap لم يتم اختبار رندر مستقل لهم على هذا السيرفر. Pose/Depth متاحان لكن إثبات الرندر الموضح هنا يخص Canny.

Qwen INT8 جاهز في فحص السيرفر؛ إنشاء/تعديل الصور لم يخضع لرندر جديد في هذه المراجعة. خدمة prompt AI الخارجية غير متصلة؛ Automatic يستخدم التنسيق المحلي. رابط trycloudflare مؤقت ويمكن أن يتغير عند إعادة إنشاء النفق. بعض الأوزان الاختيارية موجودة على /shared المؤقت.

## التحديث والرجوع
الإصدار2.1.1 يحافظ على سياسة تحديث main تلقائيًا. التعديلات المحلية على السيرفر تُحفظ قبل تسوية نسخة المصدر؛ الأوزان والمشاريع والنتائج لا تُحذف. المرجع السابق للرجوع هو الإصدار v2.1.0؛ نسخة احتياطي runtime محفوظة بواسطة copy_runtime. أوقف التحديث التلقائي بـ--no-update أثناء الرجوع، وراجع الطابور قبل أي restart.
