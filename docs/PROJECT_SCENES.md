# Scenes and shots

A project holds shared Elements and named scenes/shots. Production starts immediately: Save scene or Generate creates the required workspace. Advanced Create Scene/Create Shot tools organize work explicitly. Each shot stores its prompt, settings and reference bindings; duplication assigns new identities without duplicating historical output records.

Shared asset identities remain stable. Shot mention names/roles do not rewrite another shot or catalog names. Missing originals stay visible and block generation. Failed downloads keep a named Retry card and Save retains their identities.

Navigation checkpoints drafts and saves changed state before switching. Failed saves/revision conflicts preserve the editor. Render ownership is captured at submission, not completion. Legacy content remains accessible without guessed scene ownership. Deletion protects retained outputs/jobs/dependencies rather than implicitly removing media.

Custom reference instructions guide local compilation. Explicit structured prompts remain authoritative. Registered Realism People/Anime → Realism trigger words enter the compiled prompt and preview without rewriting the original brief.
