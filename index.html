RUN IT YOURSELF

Review. Install. Create.

Start from the source outside ComfyUI’s custom_nodes folder. The launcher prepares supported dependencies and resumes model downloads. Model weights need substantial storage, RAM and VRAM.

git clone https://github.com/underworldhistory1-ctrl/minimax-h3-interface.git
cd minimax-h3-interface
bash launcher.sh --comfy-root /path/to/ComfyUI --models-root /path/to/models

Windows: ./launcher.ps1 -ComfyRoot C:/path/to/ComfyUI
